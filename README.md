# AI-Assisted Financial Analysis & Anomaly Detection

## Project Overview

This project demonstrates how generative AI can support financial data analysis and anomaly detection in a simulated corporate expense-management scenario.

The project combines financial reasoning, Python, Excel and AI-assisted analysis to identify potentially unusual transactions while maintaining human validation and professional judgement.

> **Note:** All data used in this project are synthetic and created solely for demonstration purposes. No confidential or real company data are included.

---

## Project Objectives

The project aims to explore how AI and data analytics can improve the efficiency of financial review by:

- Cleaning and structuring financial transaction data
- Identifying potentially abnormal transactions
- Detecting duplicate or unusual expense patterns
- Analysing vendor and departmental spending
- Supporting preliminary financial risk identification
- Visualising key financial indicators
- Using AI to assist analysis while retaining human review

---

## Tools

- **Python** – Data cleaning and anomaly detection
- **Excel** – Financial data review and validation
- **Power BI** – Data visualisation and dashboard development
- **ChatGPT** – AI-assisted analytical reasoning, coding support and interpretation

## Key Analysis Areas

The analysis focuses on several potential financial risk indicators:

1. High-value transactions
2. Duplicate transactions
3. Unusual reimbursement frequency
4. Vendor concentration
5. Department-level spending anomalies
6. Weekend or unusual-date transactions

---

## Human-AI Collaboration

AI is used as an analytical assistant rather than a substitute for professional judgement.

### AI Responsibilities

- Assist with Python code development
- Suggest potential anomaly-detection logic
- Help structure financial analysis
- Summarise preliminary patterns
- Support interpretation of analytical outputs

### Human Responsibilities

- Define financial risk criteria
- Validate transaction data
- Assess whether detected anomalies are economically meaningful
- Review AI-generated outputs
- Make final financial and risk judgements
